# 成二牧區 App — Android 測試下載（不必 Expo）

> Expo／GitHub 下載在台灣／LINE 常會卡住，請用下方 **API 鏡射**。

## 建議下載（請用 Chrome 開）

下載說明頁：https://churchsheep-admin.onrender.com/download

**主要 APK（API 鏡射）：**  
https://churchsheep-api.onrender.com/downloads/churchsheep-latest.apk

1. 用 **Chrome** 打開（不要用 LINE 內建瀏覽器）
2. 下載完到「檔案／下載」點 APK 安裝（覆蓋舊版）
3. 允許「未知來源」後開啟 **成二牧區**
